# VICTOR – Personal AI Assistant

> A modular personal AI assistant designed to integrate artificial intelligence, voice interaction, persistent memory, and desktop automation.

## About

VICTOR is a personal AI assistant project developed by a Data Science undergraduate at SLTC.

The project aims to explore the development of an intelligent assistant capable of supporting academic learning, productivity, research, and personal computing.

## Planned Features

- AI-powered conversations
- Voice interaction
- Persistent memory
- Desktop automation
- Online research
- Academic assistance
- Cross-platform expansion

## Technologies

- Python
- FastAPI
- Ollama
- SQLite
- React
- Git & GitHub

## Development Status

🚧 Currently in the planning and initial development stage.

## Project Goals

- Build a modular AI assistant architecture
- Explore local AI model integration
- Develop practical AI engineering skills
- Create a real-world portfolio project
